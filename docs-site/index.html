Documentation Preview

The SSLCOMMERZ Laravel package provides a comprehensive set of tools to handle payments with ease. Below is a preview of the core sections.

Installation

Get the package via composer and publish your configuration to start.

composer require sslcommerz/laravel

Configuration

Configure your store credentials and environment settings in your .env file.

SSLCOMMERZ_STORE_ID=your_store_id
SSLCOMMERZ_STORE_PASSWORD=your_password
SSLCOMMERZ_SANDBOX=true

Payment Flow

The package handles the entire redirect and callback cycle automatically, dispatching events at every step.

Usage Example

$response = SSLCOMMERZ::initiate([
    'tran_id'      => 'TXN_12345',
    'total_amount' => 1000.00,
    'cus_name'     => 'Customer Name',
]);

Validate Transaction

Always validate transactions on the server-side using the validate method.

$validation = SSLCOMMERZ::validate($val_id);

Recurring Payments

Support for Easycheckout recurring payments. Encrypt your schedule and pass it to the initiate method.

$schedule = json_encode([
    'refer'   => 'PLAN_001',
    'acct_no' => 'CUS_123',
    'type'    => 'monthly',
]);

$encrypted = SSLCOMMERZ::getEncryptionService()->encrypt($schedule);

$response = SSLCOMMERZ::initiate([
    'total_amount' => 1000.00,
    'schedule'     => $encrypted,
    // ...
]);

Refunds

SSLCOMMERZ allows you to initiate refunds for successful transactions directly from your server. This is useful for order cancellations or partial returns.

$refund = SSLCOMMERZ::refund([
    'bank_tran_id'  => $bankTranId,
    'refund_amount' => 500.00,
    'refund_remarks'=> 'Customer request',
]);

Events

The package dispatches various events that you can listen to in your EventServiceProvider to decouple your payment logic from your controllers.

  • PaymentSucceeded
  • PaymentFailed
  • IpnReceived

Callbacks

The package automatically handles SSLCOMMERZ POST callbacks. Default routes include /ssl/success, /ssl/fail, and /ssl/cancel.

Custom Controllers

To override default callback behavior, publish the controller and update your configuration.

php artisan vendor:publish --tag=sslcommerz-controller

Update config/sslcommerz.php:

'routes' => [
    'controller' => \App\Http\Controllers\SslcommerzCallbackController::class,
]
